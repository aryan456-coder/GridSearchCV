# SDM — GridSearchCV Hyperparameter Tuning

This notebook tunes a Random Forest regression pipeline on the California Housing dataset using GridSearchCV.

Run all cells in order. It compares baseline and tuned performance on the same held-out test set using MAE, RMSE, and R², and prints measured improvement. The dataset download requires internet access on first run.
